# Prank Jessica 💗

A playful pink pixel-style date invitation website inspired by the interaction flow in the reference video.

## Flow

1. “Will you go out with me?”
2. The **No** button dodges the cursor/tap
3. Celebration screen
4. Pick a date
5. Pick an activity
6. Final date ticket + note

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy

Import this repository into Vercel. It is a standard Next.js App Router project and needs no extra environment variables.
